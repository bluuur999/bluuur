# bluuur

[Скачать bluuur для Mac](https://github.com/bluuur999/bluuur/releases/latest/download/bluuur.dmg)

Мега бесполезное приложение.

## Требования

MacBook с Apple Silicon, macOS 14 или новее и встроенным датчиком угла крышки.

## Установка

1. Скачай и открой **bluuur.dmg**.
2. Перетащи **bluuur** в папку **Applications / Программы**.
3. Запусти приложение и разреши ему запись экрана: **Системные настройки → Конфиденциальность и безопасность → Запись экрана**.
4. Перезапусти bluuur после выдачи разрешения. Эффект включается, когда прикрываешь крышку; параметры можно менять в настройках приложения.

Если macOS заблокирует первый запуск: попробуй открыть bluuur, затем в **Системные настройки → Конфиденциальность и безопасность** нажми **«Всё равно открыть»** и подтверди запуск.
